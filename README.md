# 🍡 Thai Sweets Playland — ขนมไทยเพลย์แลนด์

A collection of browser games that teach Thai culture through Thai desserts. Play mini-games, earn coins, collect sweets, and read about each one.

**▶ Live demo:** https://pear1790.github.io/thai-sweets-playland/

## Games
| Game | Description |
|---|---|
| 🍳 **Thai Sweets Kitchen 3D** (ครัวขนมไทย 3D) | Cook traditional desserts in a 3D kitchen |
| 🛶 **Floating Market Dash 3D** (ตลาดน้ำซิ่ง 3D) | Endless runner through a 3D floating market |
| 🍬 **Thai Sweets Pop** (ขนมไทยป๊อป) | Match-style puzzle with Thai desserts |
| ❓ **Quiz Rush** (ปั่นควิซ) | Fast-paced quiz on Thai culture |
| 🍲 **Tom Yum Rush** | Arcade cooking challenge |
| 🤖 **AI Prompting Guide** (สารานุกรมสั่ง AI) | Reference page on using popular AI tools |

Collected sweets go into a shared collection on the hub page, each with background on its history and meaning.

## Tech
HTML, CSS, JavaScript · [three.js](https://threejs.org/) for the 3D games · PWA (service worker, manifest) so it installs and plays offline · Kanit font bundled locally · localStorage for progress.

## Run locally
```bash
python -m http.server 5300
```
Then open http://localhost:5300.
